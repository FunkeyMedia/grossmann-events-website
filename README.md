# Getränke Grossmann Eventservice

Eigenständige, statische Website für Getränke Grossmann Eventservice in Frankfurt und im Rhein-Main-Gebiet.

## Seiten

- Startseite mit Leistungen, Sortiment, Equipment, Unternehmensprofil und Kontakt
- Impressum
- Datenschutz
- Allgemeine Geschäftsbedingungen

Die Website benötigt keine Datenbank und kann direkt auf Vercel bereitgestellt werden.
